# Willyan LP (Landing Page Portfolio)

### 🚀 Sobre o Projeto
Landing page pessoal e portfólio de links estáticos de alta performance. Desenvolvida para servir como cartão de visitas digital rápido, centralizando projetos, currículo e canais de contato de forma minimalista.

### 🛠️ Arquitetura e Stack Técnica
* **Estrutura:** HTML5 limpo e semântico.
* **Estilização:** CSS moderno integrado com foco em velocidade de carregamento (zero frameworks pesados).
* **Domínio:** Configuração de DNS personalizado via GitHub Pages utilizando `CNAME`.

### 📂 Estrutura de Arquivos Principal
* `index.html` - Ponto de entrada contendo toda a estrutura semântica e estilizações críticas inline.
* `assets/` - Diretório contendo imagens e logotipos otimizados para web.

### 🔧 Como Executar Localmente
Abra o arquivo `index.html` diretamente em seu navegador ou clone o repositório e inicialize um servidor web local.
